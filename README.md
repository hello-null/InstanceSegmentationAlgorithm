# 粘连咖啡棒最小外接矩形提取算法

基于 C++ OpenCV 4.4.0 的工业级图像处理算法，专为光电色选行业设计，实现粘连咖啡棒实例的最小外接矩形提取。

## 核心特性

| 特性 | 描述 |
|------|------|
| **开发语言** | C++ |
| **依赖库** | OpenCV 4.4.0 |
| **硬件要求** | 纯 CPU 推理，无需 GPU |
| **处理速度** | 毫秒级 |
| **应用场景** | 光电色选行业、咖啡棒分选 |

## 项目结构

```
├── samples/           # 工业高频摄像机捕捉的原始样本图像
│   ├── 简单交叉/     # 粘连程度较低的场景（10张）
│   └── 复杂交叉/     # 粘连程度较高的复杂场景（14张）
├── run_result/        # 算法处理后的结果图像（24张）
├── video/             # 算法运行演示视频
└── README.md          # 项目说明文档
```

| 目录/文件 | 描述 |
|-----------|------|
| `samples/` | 存放工业高频摄像机捕捉的原始样本图像，分为简单交叉和复杂交叉两个子目录 |
| `samples/简单交叉/` | 咖啡棒粘连程度较低的场景样本，共10张PNG格式图像 |
| `samples/复杂交叉/` | 咖啡棒粘连程度较高的复杂场景样本，共14张PNG格式图像 |
| `run_result/` | 算法处理后的结果图像，包含最小外接矩形标注，共24张JPG格式图像 |
| `video/` | 算法实际运行效果的演示视频文件 |
| `README.md` | 项目说明文档，包含算法介绍、效果展示和技术说明 |

## 技术说明

本算法针对光电色选行业中的粘连咖啡棒场景，能够在复杂交叉背景下提取咖啡棒的最小外接矩形，目前仍有错误提取的情况。算法具有以下技术优势：

- **准确性**：能够区分紧密粘连的多个目标，基本都能够准确提取咖啡棒的最小外接矩形。
- **高效率**：纯 CPU 推理，毫秒级处理速度，满足工业实时性要求
- **鲁棒性**：适用于简单交叉和复杂交叉等多种场景
